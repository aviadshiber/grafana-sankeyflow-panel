# Roadmap

The roadmap is directional, not a promise of dates. Priorities may change with user feedback, Grafana compatibility work, and maintainer capacity.

## Near term

- Complete the documented edge/path contract and diagnostic behavior.
- Validate the compatibility tier on Grafana 11.5.2 and the full-support tier on Grafana 11.6.11+.
- Add representative fixtures for circular flows, playback, data links, and accessibility.
- Publish a signed alpha release with reproducible installation guidance.

## Next

- Improve large-graph performance and renderer selection.
- Expand accessible table and keyboard interaction coverage.
- Add deployment examples for common self-managed and Helm-based Grafana installations.
- Prepare the community signing and catalog request with release evidence.

## Later

- Stabilize the public contract and define the first non-alpha release criteria.
- Broaden examples for operational, product, energy, and service-topology flows.
